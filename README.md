# 🌾 Crop Yield Prediction & Drought Monitoring System

## 📌 Overview

This project is a **Machine Learning + Flask Web Application** that predicts crop yield and monitors drought conditions using environmental and agricultural data.

It integrates:

* 📊 Data Analysis (Jupyter Notebooks)
* 🤖 Machine Learning Models
* 🌐 Flask Web Application (UI + Backend)

---

## 🚀 Features

* 🌱 Crop yield prediction using ML models
* 🌦️ Drought monitoring analysis
* 📊 Data preprocessing & visualization
* 🧠 ML-based prediction system
* 🌐 User-friendly web interface

## ⚙️ Installation

### 1. Clone the repository

```
git clone https://github.com/yasshini/Crop-Yield-Prediction-and-Drought-Monitoring.git
cd Crop-Yield-Prediction-and-Drought-Monitoring
```

### 2. Create virtual environment (optional but recommended)

```
python -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies

```
pip install -r requirements.txt
```

If `requirements.txt` is not available:

```
pip install flask numpy pandas scikit-learn matplotlib seaborn
```

---

## ▶️ Run the Application

```
python app.py
```

## 📊 How It Works

1. User enters input data through the web interface
2. Flask backend processes the request
3. ML model predicts crop yield
4. Result is displayed on the UI
